アカウント・データの削除

アプリから削除できます

サーバーに保存したデータとアカウントは、アプリ内でいつでも削除できます。

  1. アプリの「設定」を開く
  2. 「サーバーと同期 / アカウント」の画面を開く
  3. 「アカウントとデータを削除」を実行する

端末内の記録は、アプリを削除（アンインストール）すると消えます。アプリを開けない事情がある場合は、上の GitHub Issues から「データ削除の依頼」と明記してご連絡ください。本人確認のうえ、サーバー上のデータを削除します。

よくある質問

道が記録されません

①記録がオンになっているか、②位置情報の許可が「常に許可」になっているかを確認してください。省電力モードやOSの電池最適化が強いと、バックグラウンド記録が止まることがあります。OS設定で本アプリを電池最適化の対象外にすると改善する場合があります。

アカウントは必須ですか？

いいえ。ログインしなくても、記録・閲覧の基本機能はすべて使えます。ログインは、機種変更時の復元やブラウザ版での閲覧など、同期を使う場合だけ必要です。

記録した道や場所を、他の人に見られますか？

見られません。共有は、あなたが相手と範囲を選んで有効にした場合だけです。「見るだけのリンク」も、あなたが作成した場合にだけ有効で、いつでも止められます。詳しくはプライバシーポリシーをご覧ください。

機種変更で記録を引き継げますか？

はい。同期を有効にしてログインしていれば、新しい端末で同じアカウントでログインし「サーバーから復元」できます。アプリのバックアップ / 復元機能でも移行できます。

バッテリー消費が気になります

位置の記録はバッテリーを使います。記録の一時停止はアプリからいつでもできます。長時間記録しないときは、記録をオフにしてください。

道の線が実際の道とずれています

本アプリはGPSの軌跡そのものを記録しており、道路へ吸着させる補正はしていません。建物の中や地下、高い建物の間では誤差が大きくなります。生の記録は保持されるため、表示は将来の改善で変わることがあります。

ヘルスケア連携は何を読み取りますか？

連携を有効にした場合だけ、歩数・消費カロリー・心拍数・睡眠を読み取り、1日の振り返りに表示します。読み取り専用で、書き込みやサーバーへの送信はしません。
