Real Screenshots

実際のアプリ画面。

イラストやモックアップではなく、実機そのままの画面です（Android版・エミュレータ撮影）。

✨ はじめての道

今日はじめて通った道、前にも通った道、その他の道を色分けして表示。絞り込みで「はじめての道」だけを光らせることもできます。

▶ 1日を再生する

その日の移動を地図とバーで再生。「この日の全体」から、時間の流れをそのまま追えます。

🏯 市区町村の塗り率

市区町村ごとに「ぬった道 / 道路全体」の割合を表示。街をコンプリートしていく楽しさがあります。

🗓️ カレンダーで振り返る

日ごとの距離と「はじめての道」をカレンダーから。「振り返る」でその日の再生へ、「地図で見る」でその日の地図へ。

📍 場所の記録

「行った / 行きたい / 保存」の管理に、訪問日の記録、メモ、写真。何回行ったかも自動で数えます。

📷 写真ピン

写真のある場所は、地図の上で丸い写真ピンに。近くのものは「+N」でまとまって表示されます。

Why it sticks

たまっていくのが、面白い。

ぬりぬりマップの面白さは、1回開いたときじゃなくて、続けた先にあります。

🧭

自分の移動が、全部見える

塗った道が蓄積していくほど、自分がどのくらい移動して、どこまで行ったのかが地図に残っていく。「自分、いろいろ行ったな」が、目で見て分かるようになります。

📍

「この店、行ったな」がたまる

立ち寄った場所は自動で記録されて、行った店や場所がコレクションみたいに増えていく。何回行ったかも、勝手に数えてくれます。

✨

「前ここ通ったことあったんだ」

ちょっと行った先で、過去の自分の足あとと再会する。忘れていた寄り道や、昔の通学路が、地図の中に残っています。

Features

歩くほど、地図が育つ。

記録は自動。面倒な操作はいりません。ふだんの移動が、そのまま「ぬった道」として積み重なっていきます。

🎨

一度通った道は、永久にぬられる

記録をオンにしておけば、通った道が地図に残り続けます。生のGPS記録からいつでも再計算できるので、大切な足あとが消えることはありません。

🗓️

期間で振り返る

「今日 / 今週 / 今月 / 今年 / 日付指定」で表示を切替。「通った道」と「はじめて通った道」、徒歩・自転車・乗り物での絞り込みも。

🏯

市区町村の塗り率

街ごとに「道路の何％をぬったか」を表示。散歩のついでに、街をコンプリートしていく楽しさがあります。

📍

場所をためる

「行った / 行きたい / 保存」と「自宅 / 店 / その他」、メモや写真で場所を管理。しばらく滞在したお店は自動で記録されます。

🔍

お店を探せる

地図上のお店をタップ、またはアプリ内検索で、評価・営業時間・口コミをその場で確認できます。

🌃

「道だけ」モード

地図を消して、自分の道だけが光る表示にも切替可能。シンプル / 衛星 / ハイブリッドの地図、GPSの生の軌跡（欠けた部分は点線）表示にも対応しています。1日の再生画面でも、同じように地図スタイルを切り替えられます。

📖

1日の振り返り

日ごとの距離・移動時間・行った場所を一覧表示。タップすれば、その日の地図とタイムラインを再生できます。

☁️

バックアップと同期

バックアップ / 復元、Google Takeout（マイプレイス・保存済みリスト）の取り込みに対応。ログインすれば、機種変更でも記録を引き継げます。

👨‍👩‍👧

選んで共有

家族や友だちに、自分の道・場所・今いる場所を選んで見せることができます。見せる相手と内容は、いつでも変更・停止できます。

🔔

週1回の振り返り通知

今週ぬった道を、週に一度だけお知らせ（初期設定はOFF）。うるさくない距離感で、続けるきっかけに。

How it works

使い方は、3ステップ。

難しい設定はありません。

1

記録をオンにする

位置情報の許可をして、記録を開始。あとはポケットに入れておくだけです（バックグラウンドでも記録します）。

2

いつも通り出かける

通勤・通学、散歩、買い物、旅行。いつもの移動が自動で記録され、道がぬられていきます。

3

開いて振り返る

地図、1日のタイムライン、塗り率で振り返り。「はじめての道」を探しに、次は少し違う道を歩いてみたくなるはず。

あなたの記録は、あなたのもの。

nuri²マップは、位置の記録を扱うアプリだからこそ、プライバシーを最優先に設計しています。記録はまず端末の中に保存され、広告や販売に使われることはありません。このページで本物の画面を使えるのも、撮影にテストデータだけを使っているからです。
